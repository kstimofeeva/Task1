## О проекте и данных

- **Источник:** `data/table-data/buildings_prices.csv` (Данные о продажах домов в округе Кинг, штат Вашингтон, США).
- **Целевая переменная:** `price` — стоимость объекта (USD).
- **Особенности предобработки:** Для достижения высокой точности предсказаний и соответствия бизнес-требованиям, из обучающей и тестовой выборок были исключены аномальные выбросы (топ-2% элитной недвижимости по стоимости и площади). Это позволило модели сфокусироваться на основном сегменте рынка.

### Feature Engineering
Помимо базовых признаков (bedrooms, bathrooms, sqft_living, grade, condition и т.д.), были сгенерированы новые:
- `dist_to_seattle` — евклидово расстояние от объекта до делового центра Сиэтла (ключевой драйвер цены).
- `house_age` — возраст здания на момент продажи.
- `is_renovated` — бинарный флаг наличия капитального ремонта.

## Модель и метрики

* **Алгоритм:** `CatBoostRegressor`
* **Особенности обучения:**
* Нативная обработка категориальных признаков (`zipcode`, `waterfront`, `grade` и др.) без использования One-Hot Encoding.
* Целевая функция потерь (Loss Function): `MAE` для минимизации абсолютной ошибки в долларах.
* Глубина деревьев (`depth`): 10 для точной обработки пространственных координат (`lat`, `long`).


* **Достигнутые метрики на тестовой выборке:**
* **R²:** > 0.60
* **MAE:** ≤ 60 000 USD
* **RMSE:** ≤ 80 000 USD



## Быстрый старт

### 1. Установка зависимостей

Клонируйте репозиторий и установите необходимые библиотеки:

```bash
pip install -r requirements.txt

```

### 2. Запуск API

Локальный запуск через uvicorn:

```bash
uvicorn src.api:app --reload --port 8000

```

**Запуск через Docker (Рекомендуется):**

```bash
docker build -t housing-price-api .
docker run -d -p 8000:8000 housing-price-api

```

### 3. Тестирование API

Проверка работоспособности (Health check):

```bash
curl http://localhost:8000/health

```

Отправка тестового запроса с данными о доме:

```bash
bash scripts/test_request.sh

```
